Project Overview

NextPrime is a Python application designed to generate a sequence of prime numbers starting from any user provided number. The system demonstrates the mathematical concept of prime detection combined with algorithmic optimization using square root reduction.

The project includes multiple interfaces:

  • Pure Python CLI implementation
  • Colorama styled CLI interface
  • Rich based advanced terminal UI
  • Textual interactive terminal UI
  • FastAPI web interface

Core Algorithm

A number is considered prime if it is divisible only by 1 and itself. To efficiently determine primality, we only check divisibility up to the square root of the number. 

def isPrime(n):

    if n < 2:
        return False

    for i in range(2, int(n**0.5) + 1):

        if n % i == 0:
            return False

    return True

Sequence Generation

def getNextPrime(start, limit):

    primes = []
    number = start

    while len(primes) < limit:

        if isPrime(number):
            primes.append(number)

        number += 1

    return primes

The algorithm increments numbers starting from the input value and continuously checks each number for primality until the required number of primes has been generated.
